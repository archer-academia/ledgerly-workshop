Ex 2 · Tool spotlight · Skillsmith

A skill that builds and audits other skills

Skills have no enforced structure, so every author writes them differently. Skillsmith (open source, MIT, pure markdown) adds a guided design interview, generators that follow a syntax spec, and an audit.

0 · Install
npx @chrisai/skillsmith --local

pure markdown, no hooks or MCP. --local = this project, not ~/.claude (the Ex 1 trap)

1 · Discover
/skillsmith discover

an interview: identity, persona, scope, content, review → SKILL-SPEC.md

2 · Scaffold
/skillsmith scaffold

generates the skill's files from the spec, each type following its own spec

3 · Audit
/skillsmith audit

checks existing skills against the specs → a compliance score, violations, what to fix first

How it fits Ex 2

Use discover to design ship-check before writing it, and audit as a second linter. Then the workshop's own checks decide: skill_lint.py (lecture options) and skill_eval.py (does it fire, stay quiet, beat no skill).

Know before you use it

Third-party. It installs into .claude/commands/ and uses its own file types (entry point, task, framework, template, context, checklist, rules). Check where its output lands: Ex 2's checks expect .claude/skills/<name>/SKILL.md.
