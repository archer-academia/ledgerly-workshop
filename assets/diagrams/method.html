The method · TDD for agent behaviour

See the drift fail. Add one mechanism. Watch it go green

Every exercise is a drill (a fixed ticket) plus a drift check (a deterministic script that grades what the agent did and left behind).

01 · Red

Run without it

The ticket, no mechanism. Tests often pass. The drift check fails, and says why.

02 · Green

Add one mechanism

A CLAUDE.md, a rule, a skill, a hook. Same ticket, same check. Now it passes.

03 · Refactor

Make it smaller

Fewer lines, better placed, cheaper in tokens. Still green.

04 · Leftover

The red it can't fix

What this mechanism can't reach opens the next exercise.

The leftover red is the next exercise's step 0

Loaded ≠ obeyed

Every cycle has a load check (did it enter the context?) and a behaviour check (did it change what happened?).

Measure in rates

Agents are non-deterministic. A drill runs 3–5 times per variant, and 2/3 counts as a result.
